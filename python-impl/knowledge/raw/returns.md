# 退换货规则

- 生效日期：2026-01-01

## 七天退货

商品签收后七天内，商品保持完好、配件和包装齐全时，可以申请退货。
贴身用品、定制商品和已激活的软件类商品不适用七天无理由退货。
商品存在质量问题时，请提供订单号和问题描述，由客服登记售后申请。

## 退货流程

用户在订单页面提交退货申请。客服登记申请后由售后人员审核。
审核通过后，用户按照页面提供的地址寄回商品。
系统显示仓库签收后，退款通常在三个至五个工作日内原路退回。
客服登记申请不代表退款已经批准或完成。

## 运费说明

非质量问题的退货，寄回运费由用户承担。
确认属于商品质量问题时，售后人员审核后处理寄回运费。
